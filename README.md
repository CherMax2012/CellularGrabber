**Как установить быструю команду?**

Все очень просто.
1. Проверьте, скачано ли у вас приложение «Команды» (https://apps.apple.com/app/id1477376905)
2. Откройте файл .shortcut прикрепленный к релизу
3. Нажмите «Добавить»
Готово, вы установили быструю команду и уже можете её запускать!

**Как добавить команду на экран домой?**
1. Нажмите на 3 точки в правом верхнем углу команды
2. Нажмите на стрелочку вверху экрана, рядом с названием
3. Нажмите «На экран «Домой»»
4. Настройте иконку и название которые вам хочется видеть на экране Домой
5. Нажмите «Готово»
Откроется страница, где вы увидите иконку на главном экране
